# 设计分镜

段和段内的镜头已经由代码按剧本节拍切好：每段不超过单段生成上限，每切 2–5 秒，节拍归属确定。**你只写结构化的镜头字段**，程序会把它们拼成 Seedance 视频提示词。不要自己写整段提示词。

## 输入

```json
{
  "episode": 1,
  "settings": { "language": "zh-CN", "visualStyleLabel": "古装写实",
    "world": { "kind": "historical", "era": "1942 年，民国东北山村",
      "baseline": "土坯房、松木梁、纸窗、煤油灯；无电灯、无塑料、无现代织物" } },
  "maxSegmentDuration": 15,
  "cutSeconds": { "min": 2.0, "max": 5.0 },
  "segments": [{
    "id": 1, "sceneId": "S01", "durationSeconds": 12.5,
    "scene": "靠山屯坟地", "characters": ["陈九河", "老赵头"], "props": ["枣木烟袋"],
    "assets": [
      { "id": "S01", "name": "靠山屯坟地", "kind": "scene" },
      { "id": "C01", "name": "陈九河", "kind": "character" },
      { "id": "C02", "name": "老赵头", "kind": "character" },
      { "id": "P01", "name": "枣木烟袋", "kind": "prop" }
    ],
    "cuts": [
      { "index": 1, "seconds": 5.0, "beats": [ { "action": "血红的晚霞压在坟地上空。" } ] },
      { "index": 2, "seconds": 4.5, "beats": [ { "speaker": "老赵头", "line": "九河先生，您瞧那坟顶上！" } ] }
    ]
  }]
}
```

## 输出

```json
{
  "segments": [{
    "id": 1,
    "references": ["S01", "C02", "C01"],
    "blocking": "老赵头蹲在窝棚口面朝坟头；陈九河站在他身侧偏后。坟地在画面右侧。",
    "soundscape": "夜风掠过枯草，草帘摩擦，远处一声闷响",
    "music": "低沉的弦乐持续音",
    "cuts": [{
      "index": 1,
      "shotSize": "中景",
      "camera": "缓慢推镜",
      "lens": "35mm 广角，中景深",
      "cameraPosition": "老赵头 + 平视侧面",
      "composition": "三分法",
      "shot": "一名驼背老人掀开草帘趴在泥地上，两手撑地，侧头望向画面右前方",
      "eyeline": "远处坟头",
      "focus": "锁定老人侧脸与草帘",
      "stability": "稳定",
      "framePrompt": "中景，黄昏坟地，一名穿旧棉袄的驼背老人趴在窝棚口的泥地上，侧头望向坟头，血红晚霞",
      "sfx": "草帘摩擦声",
      "lighting": "血红晚霞从画面右侧低角度照入"
    }]
  }]
}
```

段号与切号必须与输入一一对应，不增不减，顺序一致。

## 每个字段怎么写

- `references` 只选这一段真正用得上的资产：**场景必须选**，角色选这一段里出镜的，道具选这一段里出现的；尽量 4–5 个，最多 6 个，只能从输入 `assets` 的 id 里选。选多了会让模型分不清参考优先级。
  - **变体选择规则**：如果输入 `assets` 中某个角色、场景或道具附带了变体条目（含 `parentId` 与 `variantLabel`，如 `C01_v1`「便装」、`S02_v1`「深夜」），请结合本段的 `lighting`、服装和动作节拍，为该资产选择**最贴合当前状态的 1 个版本**（主设定或其中一个变体）；**同一角色/场景/道具在单段内严禁同时选中主设定与变体**（程序会自动按该变体编号绑定参考图，并继承角色音色）。
- `shotSize` 只能填：`特写`、`近景`、`中景`、`全景`、`远景`。
- `camera` 只能填：`固定镜头`、`缓慢推镜`、`快速推镜`、`缓慢拉镜`、`平稳横移`、`跟拍`、`摇镜`、`手持跟随`。**一切一个运镜**，不要同时写推和摇。
- `lens` 写焦距与景深：`35mm 广角，中景深`、`50mm 标准，中浅景深`、`85mm 长焦，极浅景深`。
- `cameraPosition` 写「主体 + 角度」：`老赵头 + 平视侧面`、`坟头 + 俯视 15°`、`双人 + 平视正面`。
- `composition` 写构图法：`三分法`、`中心构图`、`对角线构图`、`对称构图`、`前景框架`。
- `shot` 是这一镜的画面：**不写角色名**，用身份或外观指代（「一名驼背老人」）；台词不要抄进来——程序会从剧本节拍逐字填。写动作遵守**四法则**：
  1. **肢体细化 + 程度量化**：具体到手、腿、头、肩背并带幅度与速度（「缓慢抬手」「快速转头」「微微低头」）；
  2. **优先低缓连续小动作**：走动、抬头、放下、攥紧，避开狂奔翻滚或多物复杂物理交互，确保动作在这几秒内做得完；
  3. **写出动作过渡衔接**：「借着转身惯性顺势抬手」「停顿一瞬后缓缓坐下」；
  4. **情绪外化成身体细节**：不写「很愤怒 / 很悲伤」，写成「下颌绷紧、指节攥白」「低头、肩膀微颤」。
- `eyeline` 写视线落点，`focus` 写焦点锁定对象，`stability` 只能填 `稳定`、`微晃`、`晃动`。
- `framePrompt` 是给图像模型出这一镜关键帧的提示词：**这一层可以直接用角色名**，写清景别、主体、动作、环境、光线与构图。
- `blocking` 写这一段的人物关系与构图逻辑：谁在哪、坐还是站、面朝哪、画面左右关系。**如果输入带有 `previousBlocking` 且 `sceneId` 与本批第一段相同，必须承接上一段末的人物站位，避免同场景跨批瞬移**；换场景时重新确立开场站位。
- `soundscape` 写这一段的环境声，**不要带 `<>` 符号**；`music` 写配乐，**不要带 `（）`**。没有就留空字符串。
- `settings.backgroundMusic` 为 `false` 时不要写 `music`——程序会忽略它，并在【约束】里要求不生成背景音乐；声景与环境音仍然要写。

## 台词与音色

- 台词行由程序拼成 `台词（角色，情绪）：{原文}`，情绪取自剧本 `delivery` 的第一个短句；你不要写台词行。
- 本段有台词的角色**尽量**放进 `references`——程序会按参考图编号加出【角色音色】块，把音色和这张脸绑在一起；参考图最多 5 个放不下时，至少保证场景和主要说话人在里面。
- 你只负责让 `references` 覆盖能放下的说话人，并让 `shot` 的画面与音色、情绪一致。

## 一致性

- `settings.world` 要落在每一镜的画面里：建筑、家具、器物、服饰、光源按 `era` 与 `baseline` 写，`baseline` 排除的元素不许出现。程序会把「世界观」一行拼进最终提示词。
- 同一场景的段沿用相同的空间描述与主光源方向，不另起设定。
- 角色外观以参考资产为准；道具按输入列表出现，不凭空添加。
- `shot` 与各字段里**严禁出现**秒数或时间范围（如 `0-3秒`、`第3秒`、`00:03`）、镜头编号（`【镜头1】`、`[Shot 1]`）、图片引用（`@图片1`、`@[图片1]`、`<Picture 1>`）、模型名或画质参数——这些由程序按真实数据补，写进去会被质量门直接打回。
- 语言跟随 `settings.language`。
