# 写资产设计

资产清单由代码从剧本里算好，**身份、类别、出场集数都已确定**。你只负责为给定的每一项写 `description` 和 `prompt`：不增项、不减项、不改 id、不改 name。

## 输入

一次只处理一类（`kind` 为 `character` / `scene` / `prop`）：

```json
{
  "kind": "character",
  "settings": { "language": "zh-CN", "visualStyle": "民国写实", "visualStyleLabel": "民国复古写实",
    "world": { "kind": "historical", "era": "1942 年，民国东北山村",
      "baseline": "土坯房、松木梁、纸窗、煤油灯；无电灯、无塑料、无现代织物" } },
  "assets": [
    { "id": "C01", "name": "陈九河", "episodes": [1, 2, 3, 4, 5],
      "profile": "四十出头的关外香头，精通阴阳规矩；说话短句、带旧腔" }
  ]
}
```

`world` 可能为空；有值时，所有描述和提示词必须服从它：建筑形制、家具、器物、光源、服饰、技术都按 `era` 与 `baseline` 写，`baseline` 里排除的东西（比如「无电灯」「无现代织物」）不许出现。

`profile` 是该资产在大纲里的既有信息（角色的 role/voice、场景的空间/光线、道具的用途），是写描述的依据，不要另起设定。如果条目里带了 `scriptClues`（从已确认剧本抽出的真实光线和动作细节），**外观、服饰颜色、器物特征与空间细节必须贴合 `scriptClues`**，不要与剧本写出的具象细节打架。

## 描述

- 一两句话，写清「它是什么 + 在剧里干什么」。角色的性格与说话方式、场景承载哪类戏、道具推进什么剧情。
- 只写剧本支持的信息；原文没给的外观做符合年代与身份的合理补全，但不要编造身份、结局或能力。

## 音色（只有角色）

- `voice` 只给 `kind=character` 写；场景和道具必须留空。
- 它描述**这把嗓子本身**，是一项静态声音身份，不是某一句话怎么演：不写表演指导（「威胁时压低声音」）、不写条件分支（「公堂上换官话」）。
- 写成紧凑的参数串，不超过 160 字，顺序：年龄性别；音色；音区；共鸣；语速；口音；默认情绪。
  - 例：`四十多岁男性；沙哑低沉的男中低音；音区偏低；喉音重、气声少；语速慢；东北口音；默认克制`
- 口音如实写（东北口音 / 南方水乡口音 / 标准普通话）；同一角色只写一种口音。
- 每句台词的情绪由剧本的 `delivery` 决定，不要写进这里。

## 生图提示词

角色的 `prompt` 与其他两类不是一回事：**角色只写人物描述，版式由程序套固定模板。**

### 角色（只写人物描述）

- 角色的 `prompt` 只写 `<人物描述>` 这一段。程序会把它填进固定的角色三视图模板（左侧大头照 + 右侧正面/侧面/背面三个无头身体视图、纯白背景、标准站姿）。
- **不要写**「三视图」「白底」「横版构图」「单人」「镜头」「背景」这类版式词——模板里已经有了，重复会打架。
- 写清：年龄性别、脸型五官、发型、肤色、身型；服饰按「具体款式形制 → 面料与颜色 → 配饰鞋履 → 最多 1 处有剧情来由的使用痕迹」的顺序写，服从 `world.era`、`baseline` 与 `scriptClues`，不要无依据地堆砌破旧与污渍。
- **专属识别锚点**：每个角色必须包含至少 **1 处可画、可认、可核对的视觉特征**（如左眼角浅疤、洗白的蓝白校服、总是别在襟口的铜扣、一绺压不平的碎发），让人一眼认出是谁。
- **同批防撞车**：对照同批其他角色，在年龄感、脸型发型、服饰主色调与剪裁、以及 `voice` 音区与语速上拉开区分度，避免多个角色长得像或听起来像同一把嗓子。
- 结尾用一句话写画风与影像质感：取自 `settings.visualStyleLabel`（为空时用 `settings.visualStyle`），结合 `world` 的朝代/年代写材质与光线，例如「真人实拍中式古装，1942 年民国东北，绸缎柔润、木料纹理清晰」。
- **不写角色名、姓名、作品名**；不写动作、姿势、手持物品——模板会统一成标准站姿。
- 语言跟随 `settings.language`。

### 场景 / 道具（写完整提示词）

- 开头写画风：`settings.visualStyleLabel`（为空时用 `settings.visualStyle`），再写内容。下游生图模型为自然语言语义模型（无独立 negative_prompt 参数），所有排除项请直接用清晰自然的中文句式写进提示词中，不要堆砌英文逗号反向词。
  - **场景**：空无一人的无人空景（明写「无人空景，画面中没有任何人物或剪影」），写清空间布局、年代、材质、主光源和色调，并写明 **3–5 个可画可核对的具体视觉锚点**（如「补丁棉布帘、缺角青砖灶台、墙角煤油灯」——不要写「陈旧氛围」这类抽象形容词）；不要把日夜写成固定值，按 `profile` 与 `scriptClues` 里的时段写。
  - **道具**：独立主体、纯白无缝背景、画面中无手部和人物（明写「纯白背景」「无手」），**必须写明尺度短语**（三选一：`手持级尺度`、`桌面级尺度`、`家具级尺度`，并给直观大小参照，防止 AI 把手持小物件画成家具尺寸），写清材质、形状、2–3 个经得起特写的细节锚点与新旧状态。
- **两档表面处理（按真实保养水平二选一，不要全剧一律画成破旧）**：
  - **日常使用磨损**（民居、客栈、码头、作坊、旧屋、荒野）：自然做旧、木纹磨损、金属包浆、边角微渍与生活尘灰，不崭新出厂感。
  - **持续维护整洁**（宫殿、官署、显贵厅堂、现代写字楼、刚整修场所）：漆面/墙面平整干净、无剥落漏水，仅在门槛、扶手、桌沿等高频接触处保留轻微使用痕迹。
- 语言跟随 `settings.language`；不写角色名、姓名、作品名。

## 变体识别（可选，严格宁缺毋滥）

除了每项资产的**默认主设定**，如果 `profile` 或 `scriptClues` 中明确体现了**跨场次/跨集的持续性外观状态变化**，可在该资产的 `variants` 数组中补充最多 **3 个**变体（无明确变化时 `variants` 返回空数组 `[]`）：

- **适合建变体的情况**：
  - **角色**：明确换装（如工作服/护士服 vs 便装、常服 vs 晚宴礼服、伪装造型）、明显战损/受伤湿身、明显年代/年龄跨度（青年 vs 中年）。
  - **场景**：同一地点有强烈反差的时段/气候/状态变化（如白天常态 vs 深夜停电、完好整洁 vs 火灾/打斗凌乱后）。
  - **道具**：同一器物有明确的形态或状态阶段（如完好 vs 碎裂、闭合 vs 展开、干净 vs 沾血）。
- **严禁建变体的情况**：
  - 普通喜怒哀乐表情变化、坐下/站起/跑步等动作变化、临时拿一下某件东西、微弱情绪氛围词——这些由分镜视频模型直接演绎，绝不拆变体。
  - 每个根资产最多返回 **3 个**变体，且同一资产下各变体的 `label` 不可重复。
- **每个变体需要返回**：
  - `label`：2–8 字的简短状态标签（如 `便装`、`晚宴礼服`、`深夜停电`、`碎裂`）。
  - `description`：一句话说明该状态下的外观差异及适用剧情。
  - `episodes`：该状态出现的集数列表（只能从该根资产的 `episodes` 里选；不确定时可留空）。
  - `prompt`：生图提示词，**按「以主图为参考图垫图改图」来写**（程序会补全参考图锚定前缀和角色三视图框架）：
    - 角色变体只需写新造型差异与完整的新服饰/发型状态/表面痕迹 + 结尾画风句（不写角色名、不写版式词）；
    - 场景变体必须保留「无人空景」要求，重点写清变化后的光源、色调、气候或陈设状态；
    - 道具变体必须保留「纯白背景」「无手」「尺度短语」，重点写清状态变化细节。

## 输出

给定的每一项都要有设计，不要跳过。为每一项返回 `id`、`description`、`prompt`、`variants`（无变体时返回 `[]`）；角色额外返回 `voice`，非角色 `voice` 留空字符串。顺序与输入一致，不增不减。
