# 规划分镜宫格画面

程序已经根据本片段镜头数与时长确定了网格规格（`2×2`、`2×3` 或 `3×3`）和每一格归属的镜头（长镜头已拆为「起势帧 / 落幅帧」，保证零黑块填满）。
**你的任务是为每一格写出精炼、连贯、可直接用于图像模型生成整张宫格联系表的单格视觉描述。**

## 输入

```json
{
  "ratio": "16:9",
  "visualStyle": "电影写实",
  "world": "现代中国校园；自然日光",
  "blocking": "美术教室，大窗在左侧晨光斜入……",
  "grid": { "layout": "3x3", "rows": 3, "cols": 3, "totalCells": 9 },
  "referenceAssets": [
    { "slot": 1, "kind": "character", "name": "林晚", "appearance": "26岁女教师，齐肩黑发，米白针织开衫" },
    { "slot": 2, "kind": "scene", "name": "美术教室", "appearance": "明亮小学美术教室，左侧大窗晨光斜入" }
  ],
  "cellPlan": [
    {
      "cellIndex": 1, "row": 1, "col": 1,
      "cutIndex": 1, "phase": "起势帧",
      "shotSize": "中景", "camera": "缓慢推镜",
      "framePrompt": "中景，美术教室讲台前，林晚翻开教案……",
      "shotExcerpt": "年轻女教师站在讲台前翻动教案……"
    }
  ]
}
```

## 输出

```json
{
  "cells": [
    {
      "cellIndex": 1,
      "visualPrompt": "中景，明亮小学美术教室讲台前，穿米白针织开衫的年轻女教师站在画面左侧翻开教案，视线投向右后排课桌，左侧大窗晨光斜入"
    }
  ]
}
```

`cells` 的数量和 `cellIndex` 必须与输入 `cellPlan` 一一对应（`1..totalCells`），不缺格、不重格。

## 写作硬规则

1. **纯画面、绝对无字**：严禁在 `visualPrompt` 里出现任何画面内文字、字幕、对白气泡、标语牌文字、镜头编号（`【镜头1】`、`Shot 1`）、格号（`格1`、`Panel 1`）、时间码或秒数（`0-5s`、`第3秒`）、图片协议标记（`@[图片1]`）。
2. **用外观特征指代人物，不写人名**：把镜头描述中的角色名统一替换成输入 `referenceAssets` 对应的核心外观特征（发型、衣着、年龄感），确保图像模型把参考图里的人脸与服装准确画进每一格。
3. **同一镜头多格（起势帧 → 落幅帧）必须拉开动作与构图变化**：
   - `起势帧` 画动作开始前的姿态、构图或切入点；
   - `落幅帧` 画动作完成后的结果、人物到达新位置或情绪落点；
   - 严禁两格写成几乎一样的重复画面。
4. **全图空间轴线与光线统一**：严格遵守输入 `blocking` 与场景参考中的固定空间关系（哪侧有窗、门在哪、主光方向）与 `visualStyle`、`world`，避免相邻格之间光源翻转或环境大变。
5. **每格控制在 25–75 字**：简洁有力，写清「景别 + 场景位置 + 主体外观与姿态动作 + 视线/构图 + 光影」，不要堆砌抽象形容词或多余标点。
